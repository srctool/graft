# 04 - CI

## 1. Why

`main` must always build and pass on all three operating systems. Path and line-ending bugs only show up on Windows, and keychain bugs only on Linux, so every PR runs on all three.

## 2. Shape

GitHub Actions, in `.github/workflows/`:

| Workflow | Trigger | Jobs |
|---|---|---|
| `ci.yml` | every PR and push to `main` | `check` × {macOS, Windows, Ubuntu}; `git-min` (Ubuntu, Git 2.38); `dco`; `spaces-path` (Ubuntu, repo in `/tmp/Graft Ünïcode/`) |
| `nightly.yml` | daily | performance benchmarks (graph layout, rendering, status on the big repo); dependency license report; recorded-fixture freshness |
| `release.yml` | tag `v*` | packaging per OS and architecture, native CLI builds, signing, notarization, checksums, SBOM, GitHub Release draft ([Release and Updates](05%20-%20Release%20and%20Updates.md)) |

## 3. API

### `check` job

1. Checkout; JDK 21 (Temurin); Gradle cache (`gradle/actions/setup-gradle`).
2. `./gradlew check`: tests, Spotless, the module-graph, import, license-header and dependency-license checks.
3. Upload test reports and screenshot diffs on failure.

### `git-min` job

Builds Git **2.38.0** from source (cached) and runs `./gradlew :core-git:test :core-repo:test -Pgit=/opt/git-2.38/bin/git`.

### `dco` job

Fails when a commit in the PR lacks `Signed-off-by:`.

### Required checks for merging

`check` (all three OSes), `git-min`, `dco`. Nightly failures open an issue automatically.

## 4. Build steps

1. `ci.yml` with `check` × 3 (G0 Task 4).
2. `git-min` and `dco` (G0 Task 4).
3. `nightly.yml` once the graph exists (G1).
4. `release.yml` before the public beta (G7).

## 5. Edge cases

| Case | Decided behavior |
|---|---|
| Windows runner is slow | Gradle configuration cache and build cache on; tests run in parallel forks |
| macOS runner minutes are costly | macOS runs on PRs and `main`, not on every push to draft PRs |
| A secret is needed (signing, notarization) | only in `release.yml`, only on tags, from GitHub environments with required reviewers |
| PRs from forks | no secrets; all `ci.yml` jobs still run |
